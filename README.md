В проекте реализованы автоматизированные тесты API для сервиса Stellar Burgers. 
Основные тестовые сценарии
Тесты создания пользователя (test_reg.py)
Создание пользователя без обязательных полей (email, password, name)
Успешное создание уникального пользователя
Попытка создания дубликата пользователя
Тесты авторизации (test_login.py)
Успешный вход с валидными данными
Попытка входа с неверными учетными данными
Тесты создания заказов и ингедиентов (test_orders.py)
Получение списка доступных ингредиентов
Проверка структуры и типов ингредиентов
Создание заказа с авторизацией и ингредиентами
Попытка создания заказа без авторизации
Создание заказа без ингредиентов
Создание заказа с невалидными ингредиентами
